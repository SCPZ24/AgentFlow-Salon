deerflow.tech
开场：DeerFlow 是字节开源的「超级智能体」底座，面向要跑几十分钟甚至几小时的任务。今天用几分钟把定位和核心模块讲清楚，方便大家判断要不要深入试用。

定位

开源的 SuperAgent Harness

把复杂目标拆成可并行、可隔离的步骤，协调子智能体、工具、沙箱与消息网关，在可控环境里完成检索、写代码、数据分析与多媒体类工作。

适合谁

需要「深度研究 + 可执行代码」闭环的团队与个人开发者。

不适合谁

只做单次问答、无工具链的简单对话场景——用普通 Chat 即可。

what
强调 harness：它不是又一个聊天 UI，而是一套把多智能体、沙箱、记忆串起来的运行时与工程约定。

DeerFlow =

Deep Exploration
and Efficient Research Flow

深度探索 + 高效研究流程：名字即产品哲学。

naming
这一页可以念全称，听众记住「研究流 + 深度」即可。

架构要点

六大支柱（节选）

子智能体

主智能体拆解任务，并行子代理、上下文隔离。

Skills

Markdown 等形式的技能模块，扩展研究 / 编码 / 媒体工作流。

沙箱

隔离文件系统与执行环境，降低工具调用风险。

记忆

长期偏好与过程沉淀，跨会话延续上下文。

MCP

对接 MCP Server，接入自定义工具与数据源。

上下文工程

摘要与压缩，支撑小时级长任务。

pillars
按听众背景挑 2–3 个展开：工程听众多讲沙箱与 MCP；研究向多讲 Skills 与记忆。
