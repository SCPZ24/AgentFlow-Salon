# A03 · E2E 链条中的人机职责演进

这张动画讲述同一条端到端链条中，AI 逐步承担更多工作，人工搬运环节随之消失，人类最终保留提出目标与验收目标。

六个时代按能力扩展组织，不标注年份，也不是各产品能力出现时间的严格分界。尤其“Skills / Workflow”表示此处选定的成熟工作流会自主运行测试，不表示所有 Coding Agent 都必须接入 Skill 才有测试执行能力。

## 两层图如何阅读

上方固定展示完成任务所需的十个环节。紫色属于人类，青绿色属于 AI；提出目标与验收目标始终属于人类。

```mermaid
flowchart LR
    A[提出目标] --> B[读取现有代码] --> C[搜索获取信息]
    C --> D[设计实现架构] --> E[设计代码] --> F[编写测试]
    F --> G[实现代码] --> H[运行单元测试] --> I[浏览器验证] --> J[验收目标]
```

下方展示实际操作：人类左栏、AI 右栏，各栏保持实际流程顺序，并沿可用高度均匀分布；多张卡片首尾对齐上下边界，单张卡片垂直居中。沿箭头阅读完整流程；跨栏箭头表示人机交接。这里的卡片不与上方节点逐一对应，例如人工复制与粘贴是为了完成任务产生的交接工作。

“编写测试”和“运行单元测试”是两件事。脚本保留先编写测试、再实现代码的顺序；前三个时代在 AI 提供代码方案后，人类编写测试，再复制、微调并写入项目。

## 六个时代

| step | 时代 | 讲解与转场重点 |
|---|---|---|
| 0 | ChatBox | AI 设计代码；人类先读取、搜索、设计架构并粘贴代码，之后还需编写测试、复制 AI 代码、微调并写入项目、执行测试和浏览器验证，最后验收。 |
| 1 | 模型能力提升 | 架构设计迁入 AI 栏。人类仍需提供资料、搬运代码并执行验证。 |
| 2 | 接入搜索 | 搜索资料迁入 AI 栏。人类仍需读取项目并粘贴代码。 |
| 3 | Coding Agent | 读取代码和编写测试迁入 AI 栏；粘贴与复制卡片消失；人工微调并写入项目被 AI 编辑项目代码替代。人类还负责运行测试、浏览器验证与最终验收。 |
| 4 | Skills / Workflow | 运行单元测试迁入 AI 栏。强调工作流把主动验证纳入完成任务的过程。 |
| 5 | Computer Use | 浏览器验证迁入 AI 栏。人类保留提出目标与验收目标，AI 承担中间八个环节。 |

Coding Agent 的变化既有职责迁移，也有工作消失。可以在此停留，指出“读取代码”从人工提供材料变成工具直接读取；“复制 AI 代码”不再是必经环节。

卡片数量不代表工作量百分比，因此不显示占比或计数。最后一幕中人类侧的目标和验收分别位于顶部与底部，AI 的中间环节均匀分布在右栏。

## 操作与状态

开场直接展示 ChatBox；五次前进走完六个时代。`→` / `Space` 前进，`←` 后退，`P` 重播进入当前时代的转场，`R` 回到首屏，`C` 打开或收起控制层，`Esc` 关闭。首屏 P 重新呈现首屏。页面底部只有六个进度点，当前点略大。

每次转场约 1.2 秒：先强调变化，再移动、增删并重排卡片，最后恢复连线并暂停。转场中再次前进只完成当前转场，不跳到下一时代。后退、重置、阶段跳转、hash 导航取消旧动画。末时代不再前进、不自动循环。

控制层提供六时代跳转、全屏和减少动效。减少动效直接显示目标时代，R 保留当前动效设置；首次加载在没有显式 motion 参数时遵循系统减少动效设置。

新链接格式为 `#step=0&motion=full`，step 范围为 0–5。刷新恢复完整落位状态，不恢复动画中间帧。旧链接的默认字段 `branch=main&decision=none&human=none&sub=0` 可读取并规范化；旧异常分支、非默认决策、子步骤和越界步骤回到开场。旧编号不保留旧场景语义。

本页是预编写的教学仿真，不实际执行代码、运行测试、调用模型或操作浏览器。测试失败后的重试循环和审批分支不在此次演示范围内。
