# EP3 动画改版交付与验证

## 交付内容

三个动画保持各自独立的 `index.html`，本地打开即可使用。画面采用同一套 1920×1080 SVG 场景；浏览器按 16:9 等比缩放，其他屏幕比例居中留边。

| 动画 | 主线重点 | 配套内容 |
|---|---|---|
| A01 | 17 个 chunk 逐条增长、四次工具调用、五次生成、最终回答 | 讲者备注，6 张 PNG |
| A02（已废弃目录，保留原行为） | 三类请求内容、基础替换、技能按需读取、历史摘要 | 讲者备注，3 张 PNG |
| A03 | 六个时代的人机职责迁移、人工搬运消失、目标与验收始终在人类侧 | 讲者备注，6 张 PNG |

操作：`→` / `Space` 前进，`←` 后退，`P` 重播，`R` 重置，`C` 打开或收起操作层，`Esc` 关闭操作层。A01 每次追加一个 chunk，动画约 1 秒；A02 约 1.8 秒；A03 每次切换一个时代，转场约 1.2 秒，随后停住。动画期间再次前进只完成本步。A01 上下文可滚动回看，继续前进时跟随新增内容。

A01 的 `step=0` 表示 3 个初始 chunk，`step=1…14` 每步追加一个。旧 `branch=main` 可用，旧失败分支与越界步骤回到开场；旧步骤编号不再对应原场景。A02 保留原有 hash。A03 新版 step 范围为 0–5；旧默认字段 `branch=main&decision=none&human=none&sub=0` 被接受并规范化，非默认分支、决策、子步骤或越界步骤回到首屏。旧编号不保留旧场景语义。

## 尚未完成的现场验证

浏览器安全策略阻止了本地 `file://` HTML 预览。此前 A01 重设计也遇到相同限制。本次 A03 没有绕过该限制；PNG 是 SVG 静态导出，不是浏览器截图。因此浏览器实际点击、滚轮与触摸事件、动态中间帧、键盘焦点、全屏、实际窗口缩放与会场投影仍需彩排确认。

建议在演示设备上依次检查：

1. 三个 HTML 断网打开，默认停在起点。
2. 连续按两次前进只完成当前动作；P 重播后仍停在当前步骤。
3. 动画中按 R、后退、阶段跳转和调整窗口，不留飞行标签或旧状态。
4. A02 在后续步骤切换 SYSTEM.md，原有补充和消息保留。
5. A03 五次前进依次走完六个时代，Coding Agent 转场正确移除人工粘贴、复制与微调卡片；最终人类侧只保留目标和验收。
6. 全屏、控制层关闭与重新呼出正常；在后排辨认输入新增条目、工具标签、测试结果和验收状态。

## 维护命令

从仓库根目录运行状态与播放器测试：

```sh
node --test PPTs/EP3/animations.test.cjs
```

更新页面后重新生成静态备份（开发环境需能解析已有的 `sharp` 包）：

```sh
node PPTs/EP3/export-animation-stills.cjs
# 只更新 A01：
node PPTs/EP3/export-animation-stills.cjs a01-react-loop
# 只更新 A03：
node PPTs/EP3/export-animation-stills.cjs a03-e2e-loops
```

`sharp` 仅用于离线 PNG 导出，HTML 页面本身无需 npm、远程字体、CDN、框架或构建服务。
