# EP3 动画改版交付与验证

## 交付内容

三个动画保持各自独立的 `index.html`，本地打开即可使用。画面采用同一套 1920×1080 SVG 场景；浏览器按 16:9 等比缩放，其他屏幕比例居中留边。

| 动画 | 主线重点 | 配套内容 |
|---|---|---|
| A01 | 输入快照、工具结果回传、四次 Call、候选交付 | 讲者备注，4 张 PNG |
| A02 | 三类请求内容、基础替换、技能按需读取、历史摘要 | 讲者备注，3 张 PNG |
| A03 | 六类职责迁移、内外闭环、异常和人类判断 | 讲者备注，4 张 PNG |

操作：`→` / `Space` 前进，`←` 后退，`P` 重播，`R` 重置，`C` 打开或收起操作层，`Esc` 关闭操作层。下一步动画约 1.8 秒，随后停住；动画期间再次前进只完成本步。分支判断不会被前进键自动代选。

原有 hash 的步骤编号和分支字段保留。A03 增加 `sub=1` 表示 Harness 阶段的第一次职责迁移；省略 sub 的旧链接仍显示完整阶段。

## 已执行的验证

- Node 内置测试：11 项通过。覆盖上下文冻结、按需读取、自定义基础、职责迁移、明确的人类决策、无效 hash、落位前不显示结果、快速前进、重置取消、重播、减少动效和窗口调整后的终态。
- 静态渲染：78 个主线、失败分支和选项组合，分别导出 1920×1080 与 1366×768，共 156 帧。
- 以实际 SVG 字体栅格测量文字边界，检查画布越界和文字相互重叠；修复了 A03 澄清分支中一处说明与职责卡重叠。最终检查未发现文字越界或重叠。
- 查看静态关键帧及场景联系表，调整了 A01 回传路线、A02 装配标签和 A03 判断按钮与闭环路径的位置。
- 交付的 11 张 PNG 从 HTML 内的同一个 `drawScene` 生成，不另做一套与页面不一致的示意稿。

状态与渲染模型测试直接执行页面内的代码。播放器测试使用虚拟时钟和浏览器 API 替身，用于验证时序与状态，不等于真实浏览器的 DOM、焦点、全屏或 Web Animations 已完成实测。

## 尚未完成的现场验证

浏览器安全策略阻止了本地 HTML 预览。本轮没有绕过该限制；PNG 是 SVG 静态导出，不是浏览器截图。因此浏览器实际点击、动态中间帧、键盘焦点、全屏、实际窗口缩放与会场投影仍需彩排确认。

建议在演示设备上依次检查：

1. 三个 HTML 断网打开，默认停在起点。
2. 连续按两次前进只完成当前动作；P 重播后仍停在当前步骤。
3. 动画中按 R、后退、阶段跳转和调整窗口，不留飞行标签或旧状态。
4. A02 在后续步骤切换 SYSTEM.md，原有补充和消息保留。
5. A03 进入 Harness 时逐张迁移职责；步骤 18 必须明确选择接受或提出新约束。
6. 全屏、控制层关闭与重新呼出正常；在后排辨认输入新增条目、工具标签、测试结果和验收状态。

## 维护命令

从仓库根目录运行状态与播放器测试：

```sh
node --test PPTs/EP3/animations.test.cjs
```

更新页面后重新生成静态备份（开发环境需能解析已有的 `sharp` 包）：

```sh
node PPTs/EP3/export-animation-stills.cjs
```

`sharp` 仅用于离线 PNG 导出，HTML 页面本身无需 npm、远程字体、CDN、框架或构建服务。
